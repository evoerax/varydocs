## Edit navigation

List each page by its path relative to the content directory, with no extension. The content root index is called 'index'.

## Change the style

Set `style` to a general-purpose style (`minimal`, `editorial`, `terminal`, `swiss`, `brutalism`, or `blueprint`) or a themed style (`gta6` or `desktop`), then preview the result.
