## 页首信息

在 Markdown 或 MDX 文件开头使用 YAML。标题会出现在导航中，描述显示在页面标题下方。

```md
---
title: 部署网站
description: 构建站点并上传静态文件。
---

## 构建
```

## 提供多种命令

在 MDX 页面中可以使用内置的 Tabs 组件。切换下方标签即可查看相应包管理器的构建命令。

<Tabs>
<Tab title="pnpm">

```sh
pnpm build
```

</Tab>
<Tab title="npm">

```sh
npm run build
```

</Tab>
</Tabs>

## 添加插图

把图片存到 `public/art/`，用它的公开路径写 Markdown 链接。在方括号里描述你希望读者留意的画面。

```md
![海滩的救生塔面朝落日，海湾对岸是一排装饰艺术风格的建筑。](/art/gta6-bay.webp)
```

![海滩的救生塔面朝落日，海湾对岸是一排装饰艺术风格的建筑。](/art/gta6-bay.webp)

## 链接其他指南

用相对路径指向源文件，例如 `[快速开始](./quick-start.md)`。构建时，VaryDocs 会将其转换为对应语言的页面链接，并检查目标文件。[打开快速开始](./quick-start.md)。
