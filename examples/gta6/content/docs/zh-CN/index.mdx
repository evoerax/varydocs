## 试用阅读器

在搜索框里输入“页首信息”，就能跳到介绍文档标题与描述的小节。点击页头的 English，可以阅读同一页的英文版。

## 使用这款风格

已有 VaryDocs CLI 项目时，在包含 `varydocs.json` 的目录中运行以下命令即可切换主题。

```sh
pnpm exec varydocs add style gta6
```
