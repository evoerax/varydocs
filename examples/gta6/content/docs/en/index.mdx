## Try the reader

Use the search box to look up “frontmatter” and open the matching section. Switch languages in the header to read the same page in Simplified Chinese.

## Use this style

In an existing VaryDocs CLI project, run the following command from the directory containing `varydocs.json`.

```sh
pnpm exec varydocs add style gta6
```
